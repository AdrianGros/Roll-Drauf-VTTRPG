# Curated free cartography assets

38 transparent Retina stamps in 5 categories: 34 at 128×128, plus lake/citadel at 256×128 and tall pine/tree at 128×256; 2 parchment textures at 1024×1024. All files are unmodified from Kenney Cartography Pack 1.0.

Source: https://kenney.nl/assets/cartography-pack
License: CC0-1.0; original License.txt included. Kenney welcomes optional attribution.

## Visual review

Inspected all 83 Retina stamps, five textures and the sample composition. Ink outlines are coherent, transparent and readable at map scale. Forest clusters, mountain ridges, villages and castles form the primary palette. Use basic parchment at low opacity; strong folds compete with labels. Preserve each stamp’s manifest aspect ratio; avoid enlarging originals beyond twice native size.

Excluded 45 stamps: modular arrow/path pieces, abstract geometric markers, redundant size variants and brick/water decorations. These need routing semantics or add browsing noise. Also excluded legacy SWF, large spritesheets, duplicate default-resolution files, unused source vectors and marketing previews.

manifest.json contains semantic IDs, German labels, categories, filenames, dimensions, anchors, original filenames and SHA-256 hashes. Archive hash and retrieval date identify provenance. Runtime uses local files only.
