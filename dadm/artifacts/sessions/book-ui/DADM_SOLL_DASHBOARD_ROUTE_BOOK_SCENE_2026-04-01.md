# DAD-M Soll: Dashboard Route Book Scene

Date: 2026-04-01
Phase: SOLL
Status: target-defined

## Objective

Define how `/dashboard` should behave after the login-scene pilot.

## Target State

- direct `/dashboard` visits should open into the same persistent spellbook scene
- the visible dashboard should be the same book page language as the login pilot
- reload should preserve the feeling that the user is still inside the open book
- old dashboard markup may remain as dormant fallback, but it must no longer be the primary rendered experience
