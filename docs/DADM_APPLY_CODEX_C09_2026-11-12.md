Status: design complete; standard/durable. Discover closed. Implements existing approved C09/P6 scope under owner's autonomous completion authorization; no new dependency or renderer. Medium risks below resolved by explicit contracts, no unresolved input or gated architecture choice. Codex self-review only, no independent review claimed.

## Boundary and contracts

Add AtlasWorld, AtlasMember, AtlasMap, AtlasPublication tables. UUID world/map/place/publication IDs; place IDs remain stable inside their world namespace, including backup restore. AtlasWorld holds revision and bounded draft graph; maps hold independent revision plus storage bundle identity and expiring lease. Publication is an immutable newly created record/object, never a mutable view of drafts. Keep only the current publication; replacing it removes the previous object after commit, old version URLs return404. No public world or anonymous access. Owner/Editor/Reader are explicit world grants, unrelated to campaign/global DM/Admin. Owner alone manages grants, publication, restore-overwrite and world deletion; Editor edits graph/maps and exports private backup, Reader receives only current publication. Own world may have no map. Existing account username grants are explicit (not sent through any external service); no grants/credentials imported from backup.

Draft graph: title(80), summary(2000), private_lore(10000), places max256 with UUID id, name(120), parent_id(nullable), map_id(nullable), pixel x/y or null, lore(10000), private_lore(10000), reader_visible boolean, links max32 known placeIDs. Maps max12, graph metadata id/title/reader_visible/km_per_pixel(nullable finite >0). Reject cycles, duplicate/unknown IDs, foreign maps/parents/links and out-of-map coordinates. Empty maps are valid; locations can exist without coordinates/maps. Stable URL /atlas?world=<uuid>&place=<uuid>; map click sets pixel coordinates; links navigate between hierarchy/map contexts. Physical scale explicitly km per map pixel, no grid-foot confusion.

Reuse personal project library list/read, server normalize_document and exact saved source revision. Explicit attach copies a source into world-owned storage, never grants/changes the personal original. Owner or Editor supplies a preview rendered by the existing snapshotFromProject/Renderer/fonts/credits pipeline and explicitly accepts visible pixels. A map bundle contains normalized rd-mapmaker document + validated same-size PNG data + bounded credit text. It is private. Edit opens the EXISTING mapmaker with atlas_world/atlas_map query parameters; a small dedicated Atlas bridge uses the existing editor/document/history/landmass renderer, bypasses personal library/drafts in this mode and saves only through the Atlas endpoint. Normal editor initialization stays unchanged. Atlas save checks fresh lease + map revision; no raster merge or CRDT. File export remains recovery. No Atlas private document is added to personal browser draft storage.

Lease contract: actor + per-tab random UUID; 120s, renewal45s while visible, exact actor/tab needed to save/release. Acquire/renew reauthorizes; another live holder409 including same actor in another tab; expired lease permits takeover. No silent forced overwrite. Map save requires integer map revision and lease token/tab. It increments map AND world revision; metadata save uses world CAS. Reconnect/reload must acquire anew; lost lease blocks shared save and keeps local document available for file export, no authority fallback. Pagehide clears private cached UI and releases best-effort; expiry is authoritative.

## Persistence and rights

All writes preliminarily check membership, then lock relevant User rows (world owner + actor in ascending IDs, same UPDATE lock as asset reservations), then fresh World row, then map if needed. Reload actor/member/owner usability after locks. This serializes shared owner quota, graph/lease/publication/revoke and prevents stale memberships/revisions. Read endpoints reauthorize every request. Apply table action permissions unchanged; no socket events/rooms or table-context authority changes.

Storage uses configured adapter; immutable new UUID keys under users/<worldowner>/atlas/<worldid> only. Max16MiB normalized map bundle, max64MiB retained bytes/world including graph/maps/current publication; max20 worlds/owner and32 explicit members/world. Shared storage_used_gb counter adjusted in same DB transaction as graph/object pointers. New uploads compensated on rollback; old objects deleted only after successful commit. Missing/provider mismatch returns503, never another storage provider or public redirect. Quotas/limits explicit errors before commit. Reader assets are served through authenticated no-store endpoints, never signed/public source URLs.

Reader publication whitelist: saved title/summary, visible map id/title/size/scale/credits, visible place id/name/parent/map/coordinates/lore and links only to other visible places. No private_lore, hidden place names/IDs, map documents, source project IDs, lease/member/storage information. A visible place requires visible ancestors and its map visible if mapped, otherwise publication rejects with actionable error. Search is over this projection only. Saved-map pixels cannot be auto-classified; full reader preview plus explicit confirmation discloses ALL selected visible map pixels. Publication CAS binds saved world revision including raster changes. Publication copies only whitelisted PNG/credits into a separate immutable storage bundle, so later draft edits never change reader assets. Reader GET/assets check current grant and active publication ID; revoke removes access on next request. Reader UI periodically revalidates/clears data on denial, plus pagehide clears memory. No private controls or author module mounted for Reader.

## Backup, UI and rollout

Owner/Editor export validated private JSON or ZIP: manifest format rd-atlas version1, world UUID, canonical draft graph, maps with UUID/document/PNG/credits and current reader snapshot. No users/grants/leases/internal keys. Exact same UUID may be restored only over own existing world with expected revision; new import may preserve UUID only if not occupied (foreign collision409), never overwrites foreign data. Restores access as owner-only for a new world; overwrite preserves existing grants but requires explicit Owner action/CAS and replaces publication atomically. Map/place IDs, references, source documents and PNGs preserved; leases cleared. ZIP uses one allowlisted atlas.json member, never extract/extractall; reject duplicates/paths/encryption/unknown members/compression, and declared/actual inflation over64MiB. JSON also bounded, all image/document/graph validators rerun. Export includes no private credentials. Deletion owner-only CAS releases accounted bytes and scoped keys.
